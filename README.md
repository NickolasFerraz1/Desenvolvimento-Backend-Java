# Fundamentos de Desenvolvimento Java

Repositório com os códigos que desenvolvi na disciplina de **Fundamentos de Desenvolvimento Java** (Infnet), incluindo exercícios de aula e trabalhos avaliativos.

## Conteúdo

| Pasta | Descrição |
|-------|-----------|
| [fundamentos-java-1900/workspace/Aula01](fundamentos-java-1900/workspace/Aula01) | Primeiro projeto Java no VS Code |
| [fundamentos-java-1900/workspace/CafeteriaApp](fundamentos-java-1900/workspace/CafeteriaApp) | Sistema de pedidos de cafeteria no terminal, feito junto com o professor |

## Tecnologias

- Java (JDK)
- VS Code com *Extension Pack for Java*

## Como executar

Cada projeto pode ser compilado e executado com `javac` e `java`. Veja o README de cada pasta para os comandos específicos.

## Sobre

Faço o código acompanhando as aulas, em vez de copiar o repositório do professor, que mantenho separado como gabarito.
